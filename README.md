# 🌊 event-streaming-lab
> "Scalable Event-Driven Architecture with Apache Kafka."

### 🚀 Key Features
- **Kafka Ecosystem**: Producer/Consumer 최적화 및 DLQ(Dead Letter Queue) 전략.
- **Stream Processing**: 실시간 데이터 파이프라인 및 정합성 보장.
- **Distributed Logic**: 분산 시스템에서의 트랜잭션 관리(Saga Pattern).
